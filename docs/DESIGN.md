# Design

The studio is a work tool, not a landing page.

## Rules

- Keep preview and controls visible together.
- Use compact panels for repeated controls.
- Prefer direct labels for beginner-friendly actions.
- Avoid decorative UI that competes with card inspection.
- Controls should stay stable while sliders and uploads change values.

## Visual Tone

Premium, focused, practical. The card art and material finish should be the loudest visual element.
