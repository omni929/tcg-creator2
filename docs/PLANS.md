# Plans

Use checked-in plans when a task has multiple steps, touches architecture, or changes user workflow.

## Lightweight Plan Format

```md
# Plan Name

## Goal

## Steps

## Verification

## Decisions
```

## Folders

- `docs/exec-plans/active`: work that is currently underway.
- `docs/exec-plans/completed`: finished plans worth keeping as project history.
- `docs/exec-plans/tech-debt-tracker.md`: small cleanup items that should not block feature work.
