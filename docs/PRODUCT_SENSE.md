# Product Sense

Card Pipeline helps a non-technical creator build premium trading card images in the browser.

## User Promise

1. Load front art, frame art, and back art.
2. Adjust card text and finish.
3. Preview the result in 3D.
4. Export polished card images or batches.

## Product Principles

- Keep the workflow visible and ordered.
- Favor plain words over technical labels.
- Make export actions obvious.
- Keep defaults attractive so users can start fast.
- Preserve reusable templates and batches.

## Current Gaps

- The app has no automated UI smoke test yet.
- Imported project JSON is normalized but not deeply validated at the boundary.
- Large WebGL bundle warning remains during build.
