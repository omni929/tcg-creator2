# Card Pipeline

Browser-first premium trading card pipeline with:

- `packages/card-schema`: shared card project types, themes, and export presets
- `packages/card-engine`: 2D composition, 3D rendering, and export logic
- `apps/card-studio`: visual editor for building and exporting premium cards

## Quick start

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
